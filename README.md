# 面部肉毒素注射

面肌痉挛（单侧、双侧）与 Meige 综合征 A 型肉毒毒素注射标准方案

## 👉 [点击打开在线版](https://wd850103.github.io/facial-botox-sop/)

网址：https://wd850103.github.io/facial-botox-sop/ （手机、电脑浏览器均可直接使用）

**离线使用：**点右上角绿色 **Code → Download ZIP**，解压后双击 `index.html` 即可（需保留同目录下的 `img/` 文件夹）。

## 内容

页面顶部可切换病种（面肌痉挛 / Meige 综合征），以下内容随之切换：

1. 诊断要点、鉴别与术前评估
2. 药物与配制（稀释表）
3. 剂量原则（单侧、双侧面肌痉挛；Meige 眼部与口下颌部）
4. 选肌、点位与剂量：按受累部位自动计算每点剂量、抽取体积和总量；以真实面部解剖图为底板标出注射点、体表标志线与禁注区；两种病并列的点位剂量对照表
5. 靶肌识别与注射层次：中文标注的面颈部浅层肌图、靶肌表（两种病分别标注）、各肌肉体表标志与定位方法
6. 操作流程，含上睑下垂、飞眉、眼袋青紫、鼻唇沟不对称的预防
7. 处方模板（面肌痉挛 A–E，Meige F–I）
8. 不良反应、处理与随访
9. 注射记录表与参考文献
