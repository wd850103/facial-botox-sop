## 内容

1. 诊断要点、鉴别与术前评估
2. 药物与配制（稀释表）
3. 剂量原则（单侧、双侧面肌痉挛；Meige 眼部与口下颌部）

5. 靶肌识别与注射层次（表情肌 / 咀嚼肌，两种病分别标注）
6. 操作流程，含上睑下垂、飞眉、眼袋青紫、鼻唇沟不对称的预防

8. 不良反应、处理与随访
9. 注射记录表与参考文献
